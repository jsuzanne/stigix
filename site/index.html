How It Works

Distributed Multi-Node Architecture

Stigix deploys seamlessly across Datacenters, Branch sites, and Cloud instances. A Leader node orchestrates Central Global Provisioning, while every peer acts concurrently as a traffic sender, custom TCP/Multicast listener, and SLA responder.

Origin
"I built this after years of writing one-off scripts for SD-WAN POCs and never finding a single lab platform that matched what I see in the field."

Every new POC used to mean another set of throwaway scripts to generate SaaS traffic, validate URL/DNS security, or time tunnel convergence. Nothing reusable, and nothing that correlated underlay router impairments with overlay application telemetry.

Stigix brings everything into one container: realistic North-South and East-West traffic generation, multicast overlay validation, live packet inspection, security policy testing, and sub-second failover measurement.

Problems it solves

  • No realistic SaaS, Custom TCP, or Multicast traffic for SD-WAN path steering
  • No single tool combining URL filtering, DNS security, C2, and PCAP replay
  • No zero-touch multi-branch orchestration with centralized configuration sync
  • No sub-second failover convergence curves with automated PoC report cards
  • No native browser packet capture or correlation between VyOS underlay and SD-WAN overlay
  • Voice RTP and Layer-2/3 IoT device simulation requiring custom scripts every time

Applications & Workflows

What engineers use Stigix for

01

SD-WAN Policy & Sub-Second Failover

Generate weighted SaaS traffic across WAN circuits, inject deterministic VyOS underlay latency or link failures, and measure exact tunnel switchover times with 1000 PPS UDP probes and exportable PoC report cards.

02

East-West Custom TCP & Multicast Overlay

Emulate ERP/POS/SCADA TCP workloads with 8 server degradation modes to prove Network RTT vs Server Response Time isolation, or validate IGMPv3 & PIM-SM multicast replication and DSCP preservation across SD-WAN branches.

03

Underlay vs. Overlay Root-Cause Correlation

Compare logical SD-WAN overlay tunnels and SASE ServiceLinks against physical VyOS router ports on a single canvas. Inspect live wire packets in the browser with Web Wireshark to isolate transport vs policy issues.

04

SASE Security, PCAP Replay & Threat Testing

Validate URL filtering, DNS sinkholing, EICAR, C2 beacons, and AI DLP policies, or replay real-world .pcap/.zip attack captures across SASE to verify firewall enforcement verdicts in real time.

05

Voice QoS & Layer-2/3 IoT Segmentation

Stream G.711/G.729 RTP calls between branches to benchmark MOS scores under congestion, while placing 100+ virtual IoT devices on the LAN via Scapy DHCP/ARP to validate device profiling and micro-segmentation.

06

Zero-Touch Multi-Branch POC Automation

Join 10+ branch nodes to a central Leader with a single token command, distribute standardized test bundles globally, switch UI context to any remote branch over NAT, and generate executive PDF reports via FastMCP.

Installation & Deployment

Up and running in under 60 seconds

ⓘ Prerequisite Docker must be installed and running on your host. No other dependency required.  Install Docker →
bash — stigix deployment
# 1. Standalone / Leader Node Deployment
$ curl -sSL https://raw.githubusercontent.com/jsuzanne/stigix/main/install.sh | bash
🚀 Stigix (All-in-One) — Starting Leader services...
✅ Dashboard active → http://localhost:8080
# 2. Zero-Touch Remote Branch Onboarding (via Magic Join Token or --controller)
$ curl -fsSL https://raw.githubusercontent.com/jsuzanne/stigix/main/install.sh | sudo bash -s -- --join STX-eyJ1cmwiOiJodHRwOi8vMTkyLjE2OC4yMDMuMTAwOjgwODAifQ
✅ Registered to Leader [192.168.203.100:8080]. Syncing 8 Global Provisioning bundles...
# 3. Manual Compose Install
$ mkdir -p stigix && cd stigix && curl -sSL -o docker-compose.yml https://raw.githubusercontent.com/jsuzanne/stigix/main/docker-compose.yml && docker compose up -d
⚡
Distributed Mesh: Every Stigix instance is both a Sender and a Responder. Once deployed, the instance immediately starts generating traffic and listening as a custom TCP application server, multicast IGMPv3/UDP receiver, HTTP echo, bandwidth speedtest, voice echo, and SLA probe target.
Linux
Docker Engine · x86 / ARM64 servers, VMs, Raspberry Pi, or any Docker-capable appliance. Host network mode for full Layer-2/3 and IGMPv3/Scapy support.
macOS
Docker Desktop / OrbStack · macOS 11+. Bridge mode. Some Layer-2 constraints apply.
Windows
Docker Desktop + WSL 2 · Windows Install Guide — full Docker container support.

Control and verify with the built-in CLI

Stigix ships a fully interactive terminal console inside the container with support for Custom Apps, Multicast, Global Provisioning, DEM probes, and Controller mesh management.

$ docker exec -it stigix stigix-cli

━━ Application: ERP-Production (:8443) ━━━━━━━━━━
✓ Listener [LISTENING] (mode: fixed_delay 150ms)
✓ Outbound [RUNNING] (2 streams to DC1)
→ Health 98/100 [OPTIMAL] (p50: 16.2ms · p95: 24.1ms)
stigix@localhost:8080 › provision publish custom-tcp-apps

stigix@localhost:8080 › controller peers
